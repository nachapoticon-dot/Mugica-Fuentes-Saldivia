# Mugica-Fuentes-Saldivia
Clase 02/10 — Trabajo práctico grupal: "Biblioteca POO"

## Integrantes
- Mugica
- Pedro Luis Fuentes Prieto
- Saldivia

## Estructura
- `libro.py`: clase `Libro`
- `socio.py`: clase `Socio`
- `biblioteca.py`: clase `Biblioteca`, que coordina préstamos y devoluciones
- `main.py`: programa principal con préstamos de ejemplo y las pruebas automáticas

## Cómo ejecutarlo
```bash
python main.py
```
Muestra algunos préstamos y devoluciones y termina con `¡Todas las pruebas pasaron!`.
